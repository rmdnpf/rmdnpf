# Prompt aset Gemini (satu percakapan; gambar pertama jadi acuan gaya)

Blok gaya — Mode A (siluet):
```
Flat 2D illustration, solid single-color silhouette in deep navy (#0B1230) with a thin electric-blue rim light on one edge,
no face detail, no text, no watermark, plain flat pure white background (#FFFFFF), whole figure visible with generous empty space on all sides.
```
Blok gaya — Mode B (berwarna):
```
Flat 2D cel-shaded animation-style illustration, bold clean thin outlines, vibrant solid colors with simple two-tone shading,
costume colors exactly as in [FILM], no painting, no 3D render, no text, no watermark, no ground shadow,
plain flat pure white background (#FFFFFF), whole figure visible with generous empty space on all sides.
```
Daftar minimum: tokoh utama berdiri + pose aksi, tokoh pendamping berdiri + pose aksi, foto/potret bersama, kelompok pendukung
(tulis tokoh yang TIDAK boleh ada), latar kota/langit/angkasa/dinding bingkai tanpa tokoh.
Aturan: bagian tubuh/jubah tidak menyentuh tepi gambar; latar putih polos, bukan "transparan".
