# Prompt pembuka konten baru (salin, isi tanda [ ])

/hyperframes Buatkan video vertikal 1080×1920 sepanjang [60–90] detik tentang [FILM / SERIAL, TAHUN], dengan formula konten Perfect Blue
(lihat templates/perfect-blue-formula/FORMULA.md di repo ini).

Detail:
- Sudut pandang: [mis. hubungan ayah–anak / twist / tema]
- Spoiler: [boleh dengan peringatan / tidak]
- Mode warna: [A siluet seperti Perfect Blue / B berwarna sesuai film]
- Narasi: Bahasa Indonesia, Cartesia (Anda siapkan naskahnya per baris; saya generate dan kirim WAV per baris)
- Workflow: /general-video, companion mode, storyboard ya.

Cara kerja: bertahap, tunggu persetujuan saya di tiap langkah.
1. Beri 2–3 konsep metafora visual (yang lahir dari tema film) + rekomendasi. Tunggu pilihan saya.
2. Tulis naskah VO per baris ([F]/[T], emosi Cartesia) dan storyboard. Tunggu setuju.
3. Beri daftar aset + prompt Gemini (latar polos putih). Saya generate dan kirim.
4. Tampilkan sketsa statis tiap frame. Tunggu setuju.
5. Setelah VO per baris saya kirim: animasi, musik/SFX orisinal, render, verifikasi, lalu kirim MP4.
Pastikan fakta film diperiksa. Jangan memakai cuplikan/poster/musik resmi.
