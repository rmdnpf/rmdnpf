# Aset Gemini (11 gambar) — dikirim setelah storyboard disetujui

Lampirkan **siluet Mima (Perfect Blue)** sebagai acuan gaya di prompt pertama, dan kerjakan semuanya dalam **satu percakapan Gemini**.
Tokoh/objek: latar **putih polos**, satu subjek utuh. Latar: **tanpa tokoh**, vertikal 9:16. PNG, sisi panjang ≥ 2048 px.
Ini siluet orisinal terinspirasi, bukan salinan desain resmi: cukup ciri umum (kostum ketat, jubah, postur).

## Blok gaya (sisipkan di setiap prompt)
```
Original illustration in the exact same style as the attached reference: solid deep navy flat silhouette with thin light
periwinkle-blue rim-light outlines, 2D anime-inspired, no gradients, no 3D, no painting, no text, no shadow.
```
